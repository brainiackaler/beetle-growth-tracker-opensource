# Backend

Spring Boot 2.7 / Java 8 API for Beetle Growth Tracker.

- [简体中文部署与使用说明](../docs/README.zh-CN.md)
- [繁體中文部署與使用說明](../docs/README.zh-TW.md)

The backend requires a private `JWT_SECRET` environment variable. Run
`mvn test` for verification or `mvn spring-boot:run` for local development.
